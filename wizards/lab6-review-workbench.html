前几轮你们完成了三个单一场景 MVP（客户诉求分类 / 供电业务知识问答 / 工单分级路由工作流）和实验五的综合系统 Agent。这个工作台帮你们完成四个评审： 1 两层验收（三个单一场景 + 协同 Agent 是否成立）→ 2 能力回注（四层：内容／工具／机制／语义）→ 3 交付决策（Go / Conditional Go / Continue Pilot / No-Go）→ 4 决策层汇报（10 段结构 + 协同 Agent 演示）。
关键判断由团队完成，AI 只做证据整理或红队。
模板不预填答案——请基于你们的证据一栏栏填。

两层验收的时间口径（先读懂再填）：第一层＝三个单一场景，课上当场验收，逐栏填实；第二层＝实验五的综合系统 Agent，课后完成后再验收，课上只做"判定标准是什么"的对照讨论，不得在课上宣称第二层已通过。

💡 讨论指引 · 问题卡（卡住时展开）▶
第一层Q-A1 翻译检验：150 字业务语言，向周主任讲清三个场景解决了什么痛点？
给自己设限：禁用 LangGraph / RAG / 准确率等技术词，只讲业务价值——派单少错、答复有依据、坐席不背锅。
第一层Q-A2 算账：自信区 85% 准确率意味着仍有约 15% 的件不在自信区，该硬分还是拒答转人工？
转人工不算错；拿不准硬归"其他"才是错。你们认为哪种更负责？
第一层Q-A3 生产差距：测过真实话务量与工单量下的并发吗？方言和口语变体呢？电价与业务规则更新后由谁维护？
样本上达标，只是"这套样本"上达标；把分母和场景写清楚。
第二层Q-B1 动态性：哪一步证明协同 Agent 在按需选能力，而不是固定调用 A→B→C？
要能指出具体轨迹证据（有一步是因为不需要而未调用），不是"界面看起来智能"。
第二层Q-B2 追问续跑：客户补充后，协同 Agent 真的从原任务继续了吗？
讨论：是真正暂停并续跑，还是只是拼了两段问答？追问是不是一次只问最关键的一个？
第二层Q-B3 人工接管：敏感事项是"真暂停"还是只是打了个标签？
讨论：request_human_review 返回 interrupted: true 之后有没有再产出答复或草稿？暂停后由哪个客户岗位接管？
全局Q-C1 双视角冲突：Echo 觉得满足、Delta 觉得还差得远——谁对？
讨论：两个视角各自在检验什么？结论如何合成？
全局Q-C2 红队：页面很漂亮、演示很顺，为什么仍可能是 Continue Pilot？
讨论：演示能跑 ≠ 生产能接管，差的是规模、边界、运维、接管能力。

第二层两条硬要求（不成立即不合格）：
1. 人工接管：命中敏感清单的件必须真暂停——request_human_review 返回 interrupted: true 后不再产出答复或草稿；只打印一句"已转人工"继续跑完，判为不合格。人工三选一（批准处置建议／要求补充材料／终止自动处理）后才继续。
2. 业务闭环：最终必须落到一个明确状态——答复（带 evidence[]）／工单草稿（submitted 恒为 false）／人工接管。

评审二：能力回注（30 分钟）★灵魂环节

用"碎石路→铺装公路"隐喻 + 四层回注（内容／工具／Workflow-Agent 机制／业务语义），判断四个对象哪些能沉淀成平台能力。判断筛子：换个客户，这个东西要不要全换？要换＝内容（不回注），不用换＝机制（回注）。

💡 讨论指引 · 问题卡（卡住时展开）▶
识别Q-D1 内容 vs 机制：协同 Agent 里哪些是岭湾的内容（不回注）、哪些是能复用的机制（回注）？
判断标准：换个客户，要不要全换？要换=内容，不用换=机制。岭湾的五类诉求口径、六条专业条线职责说法、5 份知识文档里的条款锚点是内容。
抽象Q-D2 工具契约：分类、依据检索、条线查询三件接口，换个客户要全改吗？
讨论：接口不变、只换数据？还是连接口都要重设计？
机制Q-D3 Agent 机制：受控 Agent 循环、主动澄清、人工暂停、停止条件——是岭湾专属还是通用模式？
讨论：这些机制抽象掉岭湾的壳以后，别的客户能不能直接用？
语义Q-D4 业务本体：诉求-依据条款-专业条线-服务工单-人工审核这套关系，换一个供电服务客户成立吗？
讨论：成立的部分，就是能回注的业务语义；可以自建领域模型、知识图谱或其他业务语义层。
优先级Q-D5 先铺哪条路：只给一个团队资源，先铺哪条公路？为什么？
用通用性 × 成本（或价值 × 成本）过一遍所有候选。

评审三：交付决策（15 分钟）

对 A／B／C、协同 Agent、整体给出 Go / Conditional Go / Continue Pilot / No-Go。每项必须说明：依据证据 / 剩余风险 / 补齐责任人 / 下一 Gate。不能因为界面漂亮就默认 Go，也不能通篇 Go。

💡 讨论指引 · 问题卡（卡住时展开）▶
决策Q-E1 什么证据出现，会让你把某一项从 Go 改成 No-Go？
给不出具体条件的 Go 只是表态，不是决策。
决策Q-E2 通篇 Go 说明什么？
没有风险边界的决策不是决策——把每一项的风险边界找出来；补齐责任人必须写到具体岗位／人名。
决策Q-E3 页面很漂亮，为什么仍可能是 Continue Pilot？
演示能跑 ≠ 生产能接管。差的是规模、边界、运维、接管能力。协同 Agent 一栏还要写明"待课后验收补齐证据"。

💡 讨论指引 · 问题卡（卡住时展开）▶
汇报Q-F1 对周主任 vs 对省公司数字化与网络安全部，话术能一样吗？
对周主任放大 1／2／3／6／10 段，讲价值与"能拿去汇报"；对省公司数字化与网络安全部放大 7／8 段，讲合规与"数据从哪来、到哪去、谁签字"。两线不要混。
汇报Q-F2 协同 Agent 现场演示至少两条轨迹，为什么没有固定调用全部工具？
依据类问题不需要查条线；敏感问题必须交还给人。要能在演示中讲清这个边界。
汇报Q-F3 ROI 怎么给？
给算账的框架和方向，每个数字带分母与来源，不编数字；上线后 N 周出真实数据。
质询Q-F4 接管与撤出：协同 Agent 暂停后由哪个客户岗位接管？FDE 撤出后谁维护电价与业务规则、专业条线职责？
答不出具体岗位，就等于没有责任人。
质询Q-F5 用"转人工"当挡箭牌够吗？
转人工不是免责——接收队列、负责人、处理时限、人工可见必要上下文、审核结果可回写、未处理告警、可用于评测改进，七项缺一项它就是个标签。
